# Phone Shop

Ancien projet web réalisé en 2020 autour de la gestion d'un catalogue de smartphones.


## Fonctionnalités

- Affichage d'un catalogue de smartphones
- Ajout de produits
- Modification de produits
- Suppression de produits
- Gestion simple des données
- Interface web HTML/CSS

## Technologies

- PHP
- HTML
- CSS
- Stockage des données dans un fichier texte
